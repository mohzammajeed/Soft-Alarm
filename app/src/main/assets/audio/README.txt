SoftAlarm voice files
=====================
Put your mp3 files in THIS folder: app/src/main/assets/audio/
The file name must match exactly (small letters, underscores, .mp3).
If a file is missing, the alarm plays the phone's normal alarm tone instead, so you can add files one at a time.

NAMING SYSTEM:  <voice>.mp3 = English   <voice>_pa.mp3 = Punjabi   <voice>_ur.mp3 = Urdu   <voice>_hi.mp3 = Hindi

DEFAULT FILE (free for everyone)
  default_file.mp3        <- the soft SoftAlarm default tune
